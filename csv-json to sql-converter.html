Convert CSV or JSON into SQL INSERT statements

Importing rows into a database often starts with a spreadsheet export, an API response, or a JSON data file. This generator creates INSERT statements from those sources, allowing you to choose a destination table, configure SQL identifier quoting, and group multiple rows into each statement.

Supported input formats

CSV and TSV data can include quoted fields containing commas, quotation marks, or line breaks. JSON input can be a single object, an array of objects, an array of arrays, or newline-delimited JSON records. For JSON objects, keys are used to construct the column list.

Why batch rows into INSERT statements?

A multi-row INSERT groups several rows into one SQL statement. This can reduce the number of statements needed for an import. The appropriate batch size depends on database limits, statement length, row width, server settings, and the way the import will be executed.

Review generated SQL before executing

Generated SQL does not infer your destination table's complete schema. You remain responsible for matching the target column data types, indexes, constraints, permissions, and database dialect. CSV fields are text by default to avoid accidentally changing identifiers such as postal codes or values with leading zeroes.

Frequently asked questions

Does this tool upload my data?

No. Data parsing and SQL generation take place in the browser. The page does not send your imported data to a server.

Can I generate statements for PostgreSQL and SQLite?

Yes. Select MySQL/MariaDB, PostgreSQL or SQLite. Always review generated SQL against the exact version and configuration you use.

Are CSV numbers automatically converted to numbers?

No. CSV fields are treated as text by default. You can enable type inference, but review inferred values carefully, especially identifiers with leading zeros.

Does the generator create a database table?

No. It produces INSERT statements only. Create the table and its schema separately, or adapt the generated statements to your existing table.
